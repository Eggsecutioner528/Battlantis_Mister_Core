Clock Tree & Timing Math

The original board runs from a single 24.000 MHz crystal (confirmed on the physical PCB); the FPGA implementation derives every internal clock from the MiSTer's 50 MHz input through one PLL, then a free-running divider.

PLL — 50 MHz in → 48 MHz system clock

reference_clock_frequency = 50.000 MHz
output_clock_frequency0  = 48.000 MHz  (outclk_0, phase 0°)
output_clock_frequency1  = 48.000 MHz  (outclk_1, phase 90° / 5208 ps)
48 / 50 = 24/25 → clean rational multiply/divide, no fractional VCO needed

outclk_1 drives SDRAM_CLK phase-shifted 90° ahead of clk_sys, maximizing setup margin at the external SDRAM's input register — a 180° shift was tried and reverted after TimeQuest reported a real setup violation on the clk_sys domain itself.

clk_sys (48 MHz) → chip-rate clocks

clk_12m  = clk_sys / 4   = 12.0 MHz  (CPU EXTAL)
ce_pix   = clk_sys / 8   = 6.0 MHz  (pixel clock)
2× the original board's 24 MHz crystal — every internal ratio below doubles cleanly

The main CPU's own E/Q bus-timing clocks are generated internally by the RTL CPU core from this 12 MHz EXTAL via a further /4 phase counter, matching the real HD6309E's documented external-clock relationship.

Horizontal timing — cross-checked against the factory manual

Konami's own Battlantis: Technical Information sheet specifies a 40 μs active horizontal video signal (vs. a generic monitor's 50 μs default) — the manual's own troubleshooting note for "horizontal scan too small" is literally about this mismatch on Wells-Gardner 4900-series monitors. At the RTL's 6 MHz pixel clock:

256 active pixels ÷ 6.0 MHz = 42.7 μs active window

Within measurement rounding of the manual's quoted 40 μs figure — consistent with a real board's video timing, not a MiSTer-side approximation.

Sync convention (from the factory manual): R/G/B outputs are analog positive; H-V composite sync is negative. This project's Direct Video path outputs the native 256(h)×224(v) raster unrotated — correct for a physically-rotated cabinet monitor (this is a ROT90 game), not a normal landscape CRT (see Task #24).
